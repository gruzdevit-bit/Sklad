# Sklad

Программа кладовщика: склад (товары, приход, расход, остатки, последние операции) и календарь плановых задач.

## Установка и запуск

Требования: Python 3.10+ и Flask (см. `requirements.txt`). Интернет и сборка фронтенда не нужны: шрифты, скрипты и стили лежат локально в `static/`, JS чистый.

```
pip install -r requirements.txt
python app.py
```

Сервер слушает `0.0.0.0:8080`. Проверка живости: `GET /` отвечает кодом 200.

### Данные

Товары, операции и задачи хранятся в файле SQLite. По умолчанию это `data/sklad.db` рядом с `app.py`, путь можно задать переменной `DB_PATH` (в Dockerfile это `/app/data/sklad.db`). Таблицы создаются при старте, данные сохраняются при перезапуске, пока файл базы лежит на постоянном томе.
